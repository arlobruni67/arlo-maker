How I build

Three rules every Arlo app follows.

Fast first

Graphics card encoding, GPU compositing and zero-copy paths. If it drops a frame, it is not done.

Tested, not guessed

No fake buttons and no placeholder features. Each feature ships with tests or a real recording behind it.

Friendly to use

Plain names like Video, Overlay and Sound. Pro power, without the scary menus.
